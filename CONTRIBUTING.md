# Contributing

This fork maintains iceoryx2 changes used by NVIDIA Holoscan SDK. We do not
accept external contributions or pull requests in this fork.

Submit improvements, bug fixes, and feature proposals to
[upstream Eclipse iceoryx2](https://github.com/eclipse-iceoryx/iceoryx2) and follow
its [contribution guidelines](https://github.com/eclipse-iceoryx/iceoryx2/blob/main/CONTRIBUTING.md).
Fork maintainers select and integrate upstream changes as needed by Holoscan.
